# 🩺 Medi-Chatbot

Medi-Chatbot is an **AI-powered medical chatbot** designed to provide users with quick and interactive responses to general health-related queries using a structured medical knowledge base.

## 🚀 Features

* 💬 Interactive medical chatbot
* 🩺 Provides information for common health-related queries
* 📚 Uses a structured medical knowledge base
* 🌐 Web-based interface
* ⚡ Fast responses through a Flask backend
* 🎨 Simple and user-friendly interface

## 🛠️ Technologies Used

* **Python**
* **Flask**
* **HTML5**
* **CSS3**
* **JavaScript**
* **JSON**

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/harshithareddy2303/Medi-Chatbot.git
```

### 2. Open the project folder

```bash
cd Medi-Chatbot
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python app.py
```

### 5. Open in browser

```text
http://127.0.0.1:5000
```

## 🎯 Project Objective

The objective of Medi-Chatbot is to provide a simple digital interface where users can interact with a chatbot and access general medical information in a convenient way.

## 📚 Knowledge Base

The chatbot uses `knowledge_base.json` to store structured medical information that supports the responses provided by the application.
